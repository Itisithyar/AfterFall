## 12. ITEM CATALOG / LOOT / STORAGE / REFRESH + VOXEL SURFACE BRIDGE (RECOVERED 2026-10-25)

- Item-list architecture: central item catalog (wood_basic etc.; display name, icon, stack limits, weight, properties; stacking/consumption/crafting/transfer rules) + runtime instances (inventory, storage, world pickup, loot generation). Physical world instances get unique instance IDs + location/physics/quantity; definition shared, instance unique.
- Loot→catalog: loot table (possible item IDs, quantities, probabilities, conditions) → generation algorithm → generated loot instance; persistent container state records remaining quantities (e.g., take 10 of 15 → saved state 5; reopen loads 5, not re-roll).
- Refresh system: distinguish what refreshes (catalog / UI / loot table config / container state / world loot / temp cache). Critical rule: refreshing display ≠ regenerating underlying data. Cache refresh must not restore consumed loot.
- Storage: stationary (box: stable identity + saved stacks); portable (backpack: instance-owned contents); interactive furniture (stove: fuel/ingredients/output; craft consumes → adds output). Shared inventory/persistence infrastructure, distinct behavior.
- Destruction↔inventory: projectile destroys wooden crate → destruction updates structure; inventory decides contents outcome; loot resolves drops; persistence records world state. Need explicit ownership/transition rules (who owns crate inventory before destruction; when ownership ends; which items transfer to world pickups; how transfer+destruction commit to avoid reload duplication).
- VoxelSurfaceBridge: engine-independent module translating voxel physics/damage → rendering data. S_i=(M_i,ρ_i,D_i,ϕ_i); R_i=F(S_i,L_i,N_i); D_i=clamp(d_i/d_max,0,1); Option A default (shader lighting/material, no new triangles from light); geometry path rebuilds mesh/collision when shape changes.
- Adaptive detail: ΔL=L_max−L_min; subdivide if ΔL>τ; R=f(ΔL,C,D,E). Shader handles complex lighting without new geometry; subdivision reserved for genuine geometry needs.
- Crash context: light-hit voxel → extra line/triangles; caveat: normal voxel face often already 2 triangles via GPU triangulation; shader-only default; geometry subdivision only for actual shape change.
